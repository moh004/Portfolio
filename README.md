# Moh's Portfolio

- link ==> https://portfolio-pink-chi-40.vercel.app/

A personal developer portfolio built with React, Vite, and Tailwind CSS.

Designed to showcase my projects, technical skills, and provide a way to get in touch.

## ✨ Features

- Responsive design
- Dark and light mode
- Projects showcase
- Technologies and skills section
- Contact form powered by EmailJS
- Smooth navigation

## 🛠️ Built With

- React
- Vite
- JavaScript
- Tailwind CSS
- EmailJS

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/your-repo.git
```

### 2. Navigate to the project

```bash
cd your-repo
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file in the root directory:

```env
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```

### 5. Start the development server

```bash
npm run dev
```
